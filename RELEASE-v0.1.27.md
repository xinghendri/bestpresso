# Bestpresso v0.1.27

## Light mode — Beta
- Choose **Light (Beta)** in **Settings → App experience → Bestpresso theme**.
- Dark remains the default for new and existing installations. Light mode is enabled only when you choose it and save; your choice is remembered on this device.
- Bestpresso appearance is independent of Decaid’s system theme.
- Light surfaces now extend across the homescreen, profiles, profile editor, settings, shot history, live monitoring, and supported dialogs.
- Retains the profile coverflow and its orbiting gradients, with light-mode card treatments.
- Clearer dial and keypad controls, selected states, dropdown arrows, small units, and Save/Cancel buttons. Charts use stronger light-mode colors with softer gradient fills.

## Home layout
- More breathing room between Hot water/Steam titles and their metrics in both themes, including shorter screens. Collapsed utility cards are unchanged.

Light mode is a beta: hardware-dependent dialogs still need wider testing across Decaid devices. Brewing behavior and profile settings are unchanged by this appearance update.

Install **bestpresso-v0.1.27.zip** in Decaid.
